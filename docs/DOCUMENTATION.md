# «Питомец Финни»: сопроводительная документация

Документ по разделу 5 технического задания. Сборка, запуск, разрешения и лицензии описаны в
[`README.md`](../README.md), подробная игровая логика — в [`GAMEPLAY.md`](../GAMEPLAY.md).

Версия приложения 1.0 (versionCode 1), package `ru.finny.petgame`.

## 1. Архитектура

Одно Android-приложение без сервера. Слои разделены по пакетам:

| Слой | Пакет / файлы | Что делает |
|---|---|---|
| Учебный контент | `assets/content/tasks.json`, `shop.json`, `goals.json`, `weeks.json`; `content/` (`ContentLoader`, `ContentParser`, `ContentCatalog`) | Задания, товары, цели и недели лежат в JSON и читаются при запуске. Новое задание добавляется строкой в JSON без изменения кода |
| Игровая экономика | `economy/EconomyEngine.kt`, `economy/model/` | Чистые функции без Android: проверка плана, покупка, пополнение и снятие копилки, срок цели, итоги недели, изменение настроения, сытости и роста |
| Хранение | `data/PetDatabase.kt` (Room, версия схемы 7), `data/entity/`, `data/dao/`, `data/repository/GameRepository.kt` | Сохраняет профиль и все операции; каждая операция выполняется в транзакции |
| Интерфейс | `ui/PetGameApp.kt` (навигация), `ui/screens/`, `ui/components/`, `ui/theme/` | Экраны Jetpack Compose; не содержат расчётов, только вызывают `GameRepository` |
| Настройки | `settings/UiSettings.kt`, `audio/`, `feedback/LeafHaptics.kt` | Тёмная тема, музыка, звуки, вибрация, анимации (SharedPreferences `finny_settings`) |

Поток данных: экран → `GameRepository` → `EconomyEngine` (расчёт) → Room (запись) →
`GameSnapshot` (снимок состояния) → экран.

Экраны: знакомство (`IntroScreen`), создание питомца (`PetScreen`, `PetConfirmScreen`), главный
(`MainScreen`), план (`PlanScreen`), задания (`TasksScreen`), покупки (`ShopScreen`),
копилка (`SavingsScreen`), итог недели (`PeriodResultScreen`), прогресс и справочник
(`ProgressScreen`), раздел для взрослого (`AdultScreen`), настройки (`SettingsScreen`).

## 2. Структура данных

Room-база `finny_pet.db`. Все таблицы привязаны к `profileId`.

| Таблица (сущность) | Поля | Назначение |
|---|---|---|
| `ProfileEntity` | игровое имя, имя питомца, внешний вид (шапка, очки, одежда, эмоция, цвет глаз), настроение, сытость, стадия, звёздочки роста, число удачных недель, флаг демо-режима | Профиль игрока и питомца |
| `BalanceEntity` | сумма | Доступный баланс |
| `PeriodEntity` | номер недели, статус (план / активна / закрыта), даты | Игровые периоды |
| `BudgetPlanItemEntity` | неделя, направление, сумма | План: нужное, по желанию, копилка |
| `PurchaseEntity` | товар, категория, цена, неделя | История покупок |
| `EarningEntity` | источник, сумма, неделя | Журнал начислений (у каждого есть источник) |
| `SavingsEntity` | цель, стоимость, накоплено | Копилка по каждой цели |
| `SavingsOperationEntity` | цель, тип (пополнение / снятие), сумма, неделя | История копилки, по ней считается средний взнос |
| `CompletedTaskEntity` | задание, тема, верно или нет, награда, неделя | Учебный прогресс |
| `ProgressEntity` | тип, объект, значение | Выбранная цель, полученные цели и другие отметки |

Контент (JSON):

- **Задание:** `id`, `week`, `theme` (BUDGET / SAVINGS / PAYMENTS), `type` (CHOICE — ситуация с выбором, DISTRIBUTE — распределить монеты), `title`, `story`, `question`, `reward`, `options[]` (текст, результат, `isGood`), `correctExplanation`, `wrongExplanation`, `day`.
- **Товар:** `id`, `title`, `category` (REQUIRED / OPTIONAL), `price`, `effect`, `moodDelta`, `satietyDelta`, `emoji`.
- **Цель:** `id`, `title`, стоимость, описание.
- **Неделя:** `index`, `theme`, `needs[]` (что нужно Финни на этой неделе).

## 3. Формулы и правила

**Доход** (каждое начисление пишется в журнал с источником и суммой):

| Источник | Сумма |
|---|---|
| Стартовые монеты | 30, при создании профиля |
| Карманные монеты на неделю | 30, в начале каждой новой недели |
| Задание | 5 (6 заданий — 10), за первое верное решение |
| Бонус за выполненный план | 5, при закрытии недели |
| Демо-монеты | Только в демо-режиме, по кнопке взрослого |

**Баланс:** `баланс = доходы − покупки − пополнения копилки + снятия из копилки`. Баланс не может
стать отрицательным: покупка и пополнение дороже баланса отклоняются с объяснением.

**План:** три направления, сумма направлений ≤ доступного баланса, остаток показывается. До
подтверждения план меняется свободно, после — сравнивается с фактом.

**Итоги недели** — три проверки, каждая даёт звёздочку роста:

1. Нужное куплено: куплены все товары из списка недели.
2. План соблюдён: факт по нужному и по желанию ≤ плана, в копилку отложено ≥ плана.
3. Копилка пополнена: за неделю отложено больше 0.

**Питомец.** Показатели от 10 до 100, смерти, болезни и травм нет.

- Сытость: товары дают +10…+35; при закрытии недели −30.
- Настроение: товары +3…+10, верное задание +5, план соблюдён +5, копилка пополнена +5,
  полученная цель +15; при закрытии недели −10, если нужное не куплено ещё −8.

**Рост** (не откатывается): Малыш — 0 звёздочек, Подросток — от 4, Взрослый — от 9. За неделю
можно получить до 3 звёздочек, поэтому рост требует нескольких недель.

**Срок цели:** `⌈осталось / средний взнос за неделю⌉`, где средний взнос = сумма пополнений цели
/ число недель с момента выбора цели. Перед снятием показывается новый срок.

## 5. Карта образовательного контента

Задания открываются по неделям и дням (в демо-режиме — все сразу). После ответа ребёнок видит
результат своего варианта и объяснение. Если ответ неверный, задание можно пройти снова. Полный
список — в `app/src/main/assets/content/tasks.json`.

| Неделя (тема недели) | Тема ТЗ | Заданий | Ожидаемый навык | Пример: ситуация → верная логика | Объяснение ребёнку (пример) |
|---|---|---|---|---|---|
| 1 (Нужное и желаемое) | Планирование бюджета | 15 | Распределить монеты на нужное, желаемое и копилку; расходы не больше доходов | «Первые монеты»: 20 монет, еда ещё не куплена → сначала купить еду, остаток потратить или отложить | Сначала закрывают нужное: еда и уход. Потом покупки по желанию и копилка. |
| 1 (Нужное и желаемое) | Сбережения | 2 | Поставить цель и регулярно откладывать | «Сдача в копилку»: осталось 3 монеты → положить в копилку | Даже маленькая сдача приближает мечту. |
| 1 (Нужное и желаемое) | Платежи и покупки | 14 | Смотреть цену до решения, нужное — первым | «Цена до корзины»: игрушка за 90, корм не куплен → вернуть игрушку и взять корм | Цену смотрят до решения. Нужное — первым. |
| 2 (План недели) | Планирование бюджета | 17 | Составить план на три направления | «План на неделю»: разделить 20 монет на нужное, желаемое и копилку | Ты закрыл нужное, оставил что-то по желанию и отложил в копилку. Так план работает! |
| 2 (План недели) | Сбережения | 7 | Понять срок накопления | «Домик для Финни»: домик 200, есть 50 → откладывать по 50 в неделю | Срок = сколько осталось ÷ сколько откладываешь в неделю. |
| 2 (План недели) | Платежи и покупки | 7 | Платить из нужного конверта | «Конверт нужного»: мяч не покупают из «нужного» | Каждый конверт — про своё. Мяч — из «по желанию». |
| 3 (Копим на мечту) | Планирование бюджета | 6 | Копилка после нужного | «Не вместо еды»: сначала корм, в копилку — остаток | Копилка идёт после нужного. |
| 3 (Копим на мечту) | Сбережения | 17 | Регулярно откладывать часть монет | «Копилка растёт»: отложить часть и не забыть про нужное | Ты отложил часть монет в копилку и не забыл про нужное. |
| 3 (Копим на мечту) | Платежи и покупки | 8 | Знать цену цели | «Цена мечты»: сколько стоит каждая цель | У цели есть понятная цена. |
| 4 (Покупки с умом) | Планирование бюджета | 8 | Платить из нужного направления | «Какой конверт»: осмотр у врача — из нужного | Нужное платят из нужного. |
| 4 (Покупки с умом) | Сбережения | 1 | Откладывать сэкономленное | «Сэкономил — отложи»: 3 монеты экономии → в копилку | Сэкономленное можно отложить на мечту. |
| 4 (Покупки с умом) | Платежи и покупки | 22 | Считать сдачу и сравнивать цены | «Сдача»: корм 10, дал 15 → сдача 5 | Сдача = сколько отдал − сколько стоит. Всегда проверяй сдачу. |
| 5 (Трудный выбор) | Планирование бюджета | 7 | Закрывать неожиданное нужное из желаемого | «Сначала желание»: порвалась миска → платить из «по желанию» | Неожиданное нужное закрывают желанием, не копилкой. |
| 5 (Трудный выбор) | Сбережения | 13 | Понимать цену снятия из копилки | «Снять из копилки?»: не трогать копилку ради наклейки | Каждое снятие из копилки отодвигает мечту. |
| 5 (Трудный выбор) | Платежи и покупки | 11 | Выбирать нужное при нехватке | «Не два зайца»: хватает на корм или мяч → корм | Когда хватает на одно, берут нужное. |

Связь с Единой рамкой компетенций: бюджет и «расходы не больше доходов» — план недели и запрет
минуса; нужное и желаемое — категории товаров и задания 1-й и 5-й недель; планирование покупок —
магазин с конвертами; цель и регулярные накопления — копилка и срок цели; оценка решений — итог
недели; участие взрослого — раздел для взрослого.

## 6. UX/UI и доступность

- Короткие фразы, сложные слова объяснены в справочнике («Слова» в прогрессе).
- В каждом разделе цветная шапка с названием и подсказкой, что здесь делать; на главном экране
  карточка «Следующий шаг» ведёт по циклу недели.
- Цвет раздела совпадает с цветом иконки в нижнем меню, кнопка «назад» всегда слева вверху.
- Кнопки не меньше 48×48 dp; основной текст 16 sp и больше, размеры в sp, поэтому системное
  увеличение шрифта работает. Подписи нижнего меню меньше (11 sp), потому что рядом крупные
  иконки 48 dp с тем же смыслом.
- Статусы (нужное / по желанию, верно / не совсем, настроение) подписаны словами и иконками, а не
  только цветом.
- Настройки: тёмная тема, музыка и громкость, звуки ответов, вибрация, анимации. Звук не несёт
  информации, которой нет на экране.
- Удаление профиля, снятие из копилки и завершение недели требуют подтверждения.
- Тексты не пугают и не стыдят: неудача объясняется и предлагает следующий шаг, прогресс роста
  не откатывается.

## 7. Разрешения, данные и удаление профиля

См. раздел «Разрешения и данные» в [`README.md`](../README.md). Кратко: единственное разрешение
`VIBRATE`; собираются только игровые данные на устройстве (игровое имя и питомец, без реального
имени, телефона и e-mail); в сеть ничего не передаётся; удаление — «Для взрослого» →
«Сбросить тестовый профиль».

## 10. Известные ограничения и план развития

- Задания — в основном ситуации с выбором и последствиями (151) и распределение монет (4). План:
  больше заданий-действий (собрать корзину, посчитать сдачу вводом числа).
- Контент на русском языке, интерфейс только портретный, планшетная раскладка не оптимизирована.
- Один локальный профиль на устройстве; переключение между профилями не реализовано.
- Раздел для взрослого без начисления дополнительных баллов родителем.
- План: iOS-версия, больше недель и целей, редактор контента для учителя.
