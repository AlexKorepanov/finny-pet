# Питомец Финни

Прототип Android-приложения по финансовой грамотности для детей 7–11 лет
(хакатон Департамента финансов Москвы).

## Стек

- Kotlin, Jetpack Compose, Room (SQLite)
- Package: `ru.finny.petgame`
- Android 8.0+ (API 26), портрет
- Без интернета, аккаунтов и разрешений

## Быстрый запуск

1. Откройте проект в Android Studio (Ladybug / актуальный AGP).
2. Sync Gradle.
3. Запустите конфигурацию `app` на эмуляторе или устройстве.

Сборка debug APK:

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Демо для экспертов

1. Пройдите интро → создайте профиль и питомца.
2. В разделе **Для взрослого** решите пример и включите **Демо-режим** (все задания открыты).
3. Пройдите цикл: план → задание → покупки → копилка → завершить период.
4. **Сбросить тестовый профиль** (раздел «Для взрослого», с подтверждением) возвращает игру к
   исходному состоянию — к первому запуску, и обязательный сценарий можно пройти заново.

**Локальный игровой профиль** хранится только на устройстве (Room + настройки звука в
SharedPreferences): в приложении нет разрешения на интернет, облачное резервное копирование и
перенос на другое устройство отключены (`allowBackup="false"`, `backup_rules.xml`,
`data_extraction_rules.xml`).

## Структура

- `economy/` — расчёты бюджета, покупок, копилки, оценки периода
- `content/` + `assets/content/*.json` — задания, товары, цели
- `data/` — Room и `GameRepository`
- `ui/` — экраны Compose
